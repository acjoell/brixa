# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público para reportar una vulnerabilidad.

Usa el reporte privado de GitHub: en la pestaña **Security** de este repositorio, pulsa **Report a vulnerability**.

Incluye, si es posible:

- La versión de Brixa y de Node.js.
- Los pasos para reproducir el problema.
- El impacto que crees que tiene.

## Alcance

Esta política cubre el CLI, las plantillas y el código que genera. Brixa 0.1.0 no incluye autenticación, RBAC ni multitenancy.

La guía interna de diseño de seguridad está en `.agents/rules/SECURITY.md`.
